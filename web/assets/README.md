# Assets de la interfaz

Acá va el logo de **VIUrewards**: un archivo `.webp` animado con fondo
transparente, provisto por el creador.

Mientras el archivo no esté, el encabezado usa el texto "VIUrewards" como
marcador. Cuando esté, se referencia desde `web/index.html` como
`/web/assets/logo.webp` (el dashboard sirve `/web/` de forma estática).
